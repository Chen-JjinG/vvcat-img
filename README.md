# 净色 · AI 图像色块降噪

纯静态网页工具：消除 AI 生成图里常见的脏白点、色块和色度噪点，并用选区、画笔、油漆桶做手工修饰。无需后端，也不依赖 npm 或 CDN。图片始终在你的浏览器本地处理，不会上传。

## 本地打开

任选一种方式：

**推荐（本地静态服务器）**

在本目录执行：

```bash
python3 -m http.server 8080
```

然后在浏览器打开 `http://localhost:8080/`。

也可以使用 `npx serve` 或任意静态服务器。

**直接打开 `index.html`**

双击或用浏览器打开 `index.html` 通常也能用。若某浏览器在 `file://` 下拦截 Web Worker，降噪会自动改在主线程运行（大图时界面可能短暂卡顿）。如果降噪失败，请改用上面的本地服务器。

打开后可点击「加载示例图」查看 `demo/sample.png` 的效果。地址带上 `#demo` 或 `?demo=1`（例如 `http://localhost:8080/#demo`）会自动加载同一张示例图。

## 部署到 GitHub Pages / 腾讯云 Pages

站点文件已经在仓库根目录（`index.html`、`css/`、`js/`、`demo/`）。这是无构建的静态站点，入口是 `index.html`，不需要 npm 或服务端路由。

合并进 `main` 之后，把 Pages 指到该分支的根目录：

**GitHub Pages**

在仓库 Settings → Pages 中，Source 选择 `main`，目录选 `/`（根目录）。不需要填写构建命令。

**腾讯云 Pages**

把本仓库当作静态站点部署。合并后选择 `main`，站点根目录用仓库根，无需构建步骤，入口文件为 `index.html`。

站点若在子路径下，请保持现有相对路径（`css/...`、`js/...`、`demo/...`），不要改成以 `/` 开头的绝对路径。CloudPages 或其他静态托管同样把根目录当作站点根即可。

## 使用说明

1. 打开或拖入一张图片，或加载示例图。
2. 用右侧「一键降噪」清理色块。可调「强度」和「边缘保留」。若已有选区，「自动」范围只会处理选区。
3. 需要时用魔法工具（点按颜色即圈出连通区域，左右拖动调整容差）、套索、矩形或椭圆建立选区。
4. 用画笔、橡皮、油漆桶、涂抹在当前图层上继续修。点「＋」可新建图层；降噪仍写回背景，背景不能删除。
5. 按住「对比原图」或打开分屏对比。导出为 PNG（会合并可见图层）。

降噪写回背景图层，可撤销。快捷键见应用内「？」面板。

## 降噪方法

在 Lab 色彩空间中工作，色度平滑强于亮度，避免把线稿和发丝边缘抹糊：

- 形态学开/闭运算与小窗口中值，找出孤立的浅色/偏色色块；
- 只在「强异常」像素上做连通域，避免整片皮肤被连成一块；
- 用色块外围的稳健颜色填回；
- 默认开启「纯净平涂」（v7，调色板优先的整图清洗）：先估计画面上大约有哪些有意的平涂色（纯白纸面、纯黑线稿、头发/裤子的深色填色、皮肤、背心红、条纹/鞋面白、鞋侧灰、颈部阴影等），再把整张图向这些主色靠拢。近白（背景、脏条纹、名牌、眼白）收成纯白 `[255,255,255]`；近黑线稿收成纯黑 `[0,0,0]`，并与头发/裤子的深色填色分开，以免深色衣物上的线稿消失；每个色块内部的 AI 脏斑、杂色碎点和线稿里的中灰孔洞吸到该块的主导色。夹在线稿和有色填色之间的浅色抗锯齿不得收成纯白（否则会在描边外圈出一条白边），这些像素会贴到相邻填色或保留 1px 的墨↔填色过渡。背心红白条、眼皮与眼白、鞋侧灰等有意区分的平涂不会被合并。结构边缘保留很短的抗锯齿，避免硬切出发际线和条纹边。关闭该选项后只做较轻的去色块。
- 强度默认 90%、边缘保留默认 88%，均可在侧栏调节。一键降噪（默认参数）即走上述清洗路径。
- 在调色板清洗之前，仍会做色块修补、结构感知平涂、把肤色贴到线稿旁的浅色光晕上，以及对非边缘色度的小半径引导滤波；只在结构边缘的墨线一侧做很轻的锐化（不提亮浅色边缘）。

`demo/before.png` 与 `demo/after.png` 是对示例图跑同一套算法得到的对照。`demo/user-hd-original.png` 与 `demo/user-hd-after-v7.png` 是高清人设稿的对照，`demo/user-hd-cmp-v7-*.png` 是局部对照；`demo/user-original.png` 与 `demo/user-after-v7.png` 是同一角色的脸部裁切对照。`demo/ui/` 是界面截图。

## 限制

- 建议处理约 1600 万像素以内的图片。更大的图可以打开，但降噪会较慢，撤销步数也会减少。
- 导出为当前画布的原始分辨率 PNG。
- 撤销约 30 步（很大的图会自动减少步数）。
- 画笔支持触控笔压感（Pointer Events 的 pressure）；普通鼠标用工具栏里的大小和不透明度。
- 不适合当作通用「去胶片颗粒」滤镜：目标是去掉 AI 图上那些孤立的脏色块，同时尽量保住清晰的线稿边缘。
