# 净色 · AI 图像色块降噪

受 Procreate 启发的纯静态网页编辑器（深色界面与自动选区的点按、拖动容差方式相近；与 Procreate 无隶属关系）。用来给 AI 生成图降噪，尤其是把动漫皮肤上的斑驳色块收成干净的赛璐璐平涂。自带自动选区、油漆桶、画笔，以及橡皮、涂抹、吸管等修饰工具。

无需后端，也不依赖 npm、打包器或 CDN。图片始终在浏览器本地处理，不会上传。

## 本地打开

在仓库根目录执行：

```bash
python3 -m http.server 8080
```

然后在浏览器打开 [http://localhost:8080/](http://localhost:8080/)。也可以换成其他静态服务器，入口都是根目录的 `index.html`。

## 示例模式

地址带上 `#demo` 或 `?demo=1` 会自动加载 `demo/sample.png`，例如：

- `http://localhost:8080/#demo`
- `http://localhost:8080/?demo=1`

页面上的「示例图」按钮效果相同。`demo/` 里其余图片是随工具保留的对照素材（`before.png` 与 `sample.png` 相同，`after.png` 为处理后的对照；另有 `user-original.png`、`user-before*`、`user-after*` 及 v2 / v3），页面不会自动打开它们。

## 静态托管

可以放到 GitHub Pages，或任意静态托管。不需要构建步骤，也不需要服务端路由。

在 GitHub 上开启 Pages 时，Source 选择要发布的分支（例如 `main`），目录选 `/`（根目录）。站点若在子路径下，请保持现有相对路径（`css/...`、`js/...`、`demo/sample.png`），不要改成以 `/` 开头的绝对路径。本仓库没有代为开启 Pages。

## 直接用 file:// 打开

双击 `index.html` 通常也能编辑。若浏览器在 `file://` 下拦截 Web Worker，降噪会自动改到主线程运行（进度文案会变成「正在主线程降噪…」，大图时界面可能短暂卡顿）。示例图或降噪若失败，请改用上面的本地服务器。

## 使用说明

1. 打开或拖入一张图片，或加载示例图。
2. 用右侧「一键降噪」清理色块。默认 **强度 90%**、**边缘保留 88%**、**「纯净平涂」开启**。范围默认是「自动」：已有选区时只处理选区，否则处理整张图。也可以改成「仅选区」或「整张图」。
3. 用自动选区（点按颜色，向右拖提高容差、向左降低；Shift 相加，Alt 相减）、套索、矩形或椭圆建立选区。
4. 用画笔、橡皮、油漆桶、涂抹在「修饰」图层上继续修。修饰层可以单独擦掉或隐藏，不会直接改掉背景像素。
5. 按住「对比原图」或打开分屏对比。导出为 PNG（当前画布分辨率，合并可见图层）。

降噪写回背景图层，可撤销。快捷键见应用内「？」面板（Windows 上把 ⌘ 换成 Ctrl）。

## 降噪方法

在 Lab 色彩空间中工作，色度平滑强于亮度，避免把线稿和发丝边缘抹糊：

- 形态学开/闭运算与小窗口中值，找出孤立的浅色或偏色色块；
- 只在「强异常」像素上做连通域，避免整片皮肤被连成一块，再向较弱残差生长；
- 用色块外围的稳健颜色填回；
- 默认开启「纯净平涂」：在低结构梯度的大色块（皮肤、平涂）里按连通区域收成主导色，再合并相近色块、把填色生长到线稿浅色一侧的抗锯齿环，并吸收被包围的残点，让动漫皮肤接近干净纯色；同时用粗尺度亮度差拦住眼皮等软过渡，避免把眼白涂成肤色。线稿、瞳孔、发丝和硬边保持受保护。关闭「纯净平涂」后会跳过这套收色（合并相近色块、生长到抗锯齿环、吸收残点），更接近轻度去噪；
- 最后对非边缘色度做小半径引导滤波，并在结构边缘做很轻的锐化。

侧栏里的强度、边缘保留和「纯净平涂」会传给同一套算法（Web Worker 里的 `js/denoise-worker.js`，或主线程上的 `DenoiseCore.denoise`）。

## 文件

| 路径 | 作用 |

| `index.html`、`css/`、`js/` | 页面。脚本用普通 `<script>` 标签加载，没有构建步骤。 |

## 限制

- 超过约 800 万像素时，状态栏会提示降噪可能较慢。撤销步数随尺寸减少：约 200 万像素以内 30 步，更大依次降到 20、12、8 步。
- 导出为当前画布的原始分辨率 PNG。
- 画笔在触控笔上使用 Pointer Events 的 pressure；普通鼠标用工具栏里的大小和不透明度。
- 目标是去掉 AI 图上孤立的脏色块并尽量保住线稿边缘，不是通用的胶片颗粒滤镜。
